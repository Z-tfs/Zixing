# Reference outlines

Glyph outlines used as a visual reference in the editor. They are never used to build Zixing glyphs.

## source-han-sans-regular.json

- Font: Source Han Sans SC Regular, Version 2.005
- Source: <https://github.com/adobe-fonts/source-han-sans>, `release` branch, `OTF/SimplifiedChinese/SourceHanSansSC-Regular.otf`
- License: SIL Open Font License 1.1 (<http://scripts.sil.org/OFL>). © 2014-2025 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
- Glyphs: 十 人 小 打 口

Outlines are copied unchanged from the font: font units, y-up, UPM 1000, em box y −120…880. Each contour is a list of nodes in the same shape as the core `Contour` type (`p`, optional `in` / `out` absolute handles). Outer contours are counter-clockwise, counters are clockwise.

The font file itself is not in the repository. The data was extracted once with fontTools; to add glyphs or weights, extract again from the same source.
